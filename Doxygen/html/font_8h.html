Detailed Description

Librería de fuente tipográfica Bitmap 8x8 para renderizado en pantalla TFT.

  • Este archivo contiene la definición estática de una fuente monoespaciada basada en mapas de bits (bitmaps). Está diseñada para ser ultraligera, evitando el uso de librerías gráficas pesadas que puedan comprometer el determinismo del microcontrolador RP2040.

const uint8_t font8x8[96][8]

Matriz constante que define los mapas de bits para caracteres ASCII imprimibles.

Contiene 96 caracteres, correspondientes a los códigos ASCII del 32 (Espacio) al 127 (Delete). Cada carácter está representado por un arreglo de 8 bytes, formando una cuadrícula de 8x8 píxeles.

  • - Cada byte (ej. 0x18) representa una fila horizontal del carácter.
  • Los bits en '1' indican que el píxel debe encenderse (color de texto).
  • Los bits en '0' indican que el píxel debe apagarse (color de fondo).
  • El bit más significativo (MSB) corresponde al píxel más a la izquierda de la fila.
