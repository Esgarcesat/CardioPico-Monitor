Detailed Description

Firmware principal del Cardiopico-Monitor.

  • Sistema de instrumentación biomédica multimodal basado en RP2040. Realiza la adquisición de señales de electrocardiograma (ECG), fonocardiograma (PCG), cinemática mediante acelerómetro (MPU6050), almacenamiento masivo en tarjeta SD (FatFS) y renderizado en tiempo real en pantalla TFT ILI9341.

bool timer_adquisicion_callback ( struct repeating_timer * t)

Función Callback de interrupción del temporizador de hardware (Hardware Timer ISR).

  • Se ejecuta automáticamente con un periodo estricto (e.g. 5ms). Se encarga del muestreo de bajo nivel de los canales ADC y avisa al hilo principal cuando los datos están listos.
  • Parameters
    tPuntero a la estructura del repeating_timer.
    Returns
    true Para mantener activa la repetición del temporizador.
